# Drawing your system diagram

The assignment says you must create the diagram yourself; an AI-generated diagram earns zero. This file is guidance, not a diagram or a submission substitute.

1. Open a diagramming tool such as draw.io or Lucidchart and create a blank diagram.
2. Decide whether a flowchart or component diagram better explains your own design.
3. Identify your program's starting point and mark it clearly.
4. Add every major step or component in your MVP. Think through where input is checked, where sessions are stored, how summaries are computed, and how saved records are read and written.
5. Connect the shapes yourself and label each arrow with what moves between them, such as user input, a validated record, a list of sessions, a summary, or file contents.
6. Check that recording, saving, loading, and reviewing practice all appear. Include important error paths if using a flowchart.
7. Ask whether someone could understand the tracker without reading the code or README.
8. Save the editable source in `docs/`, export a PNG/JPG, and insert the image into the proposal. Keep both files for submission.

I can review the diagram you draw for missing components, unclear arrows, and readability.
